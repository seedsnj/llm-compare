## 当前版本摘要

- React 18 + TypeScript + Vite 纯前端应用。
- 直接依赖 4 个，低于 5 个硬上限。
- 定价来自 models.dev；能力证据来自 LMArena 和 ai-model-index。
- 综合 Profile 权重为高难度 20%、通用开发 60%、日常信息 20%。
- 日期化测试固件位于 `tests/fixtures/`，由 Node 内置 test runner 校验。
- 无法精确匹配的数据显示「无数据」或「无可信数据」，不以零值或模糊匹配补齐。
