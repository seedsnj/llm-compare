# 路线图

- 最后更新：2026-11-06
- 文档版本：1.0.0

## 状态说明

- **Now**：已经确认并应优先处理的稳定性或工程事项。
- **Next**：已识别、需要排期的事项，不代表具体发布日期。
- **Candidate**：候选功能，尚未获得产品承诺。
- **Non-goals**：当前明确不做的事项。
- Candidate 不等于承诺；只有控制器明确接受并写入需求后，才能进入 Now 或 Next。

## 已确认范围

Stage 0–3 的产品范围已经完成：

- Copilot 用量计费价格表。
- 可开关缓存输入价。
- 模型/供应商过滤、排序和最多 3 个 Pin。
- 手动价格更新与 localStorage。
- 三维 Benchmark Profile 与综合性价比。
- 五类开发任务预测。
- 日期化测试固件与项目文档。

目前没有已经确认但尚未实现的产品功能扩张。

## Now：稳定性

### R-01 空数据与数值范围防护

**问题**：当有效模型没有价格或某类能力数据为空时，范围计算可能得到 `Infinity` 或 `undefined`。

**目标**：

- 空集合返回明确的无数据状态。
- 价格条、成本梯队、能力条和性价比不产生 `NaN`。
- 添加对应边界测试。

**完成标准**：空价格集合、空能力集合和单样本集合均能安全渲染。

### R-02 快照与 localStorage 结构验证

**问题**：缓存读取目前只验证模型数组长度，没有逐字段验证。

**目标**：

- 验证 capturedAt、模型 ID、价格字段、状态和来源。
- 损坏缓存自动回退内置快照。
- 以共享验证函数避免运行时代码与固件测试规则分叉。

**完成标准**：结构损坏但长度正常的缓存不会进入计算流程。

### R-03 数据时效提示

**问题**：页面展示快照日期，但不会主动提示快照过期或新模型缺少能力数据。

**目标**：

- 根据可配置阈值提示 pricing、capability、benchmark 快照过期。
- 价格更新后出现的新模型明确显示“尚无性能快照”。

**完成标准**：用户能从主界面判断数据是否足够新，不需要自行比较日期。

## Next：测试与发布

### R-04 TypeScript 类型检查

**目标**：

- 在不突破 5 个直接依赖上限的前提下建立类型检查方案。
- 如无法同时保留 React 类型包和 TypeScript，需要明确控制器裁决。

**完成标准**：CI 可运行类型检查，失败会阻止合并或发布。

### R-05 浏览器验证与 CI

**目标**：

- 将现有的手动静态检查固化为可运行的浏览器 smoke test。
- 覆盖筛选、排序、Pin、缓存列 DOM、离线 fallback 和更新失败。
- 配置 CI 运行 `npm test`、构建和浏览器 smoke。

**完成标准**：关键交互在无人工操作时自动验证。

### R-06 发布版本统一

**问题**：`package.json` 当前为 `0.0.0`，而文档版本已独立增长。

**目标**：

- 确立应用版本、文档版本和固件日期的关系。
- 至少为应用发布建立语义版本或日期版本。

**完成标准**：README、package.json、changelog 和 tag 使用同一发布标识。

## Next：数据运维

### R-07 Benchmark 更新流程

**目标**：

- 为 Terminal-Bench、SWE-bench Verified 和 ClawMark 建立可重复的构建期收集脚本。
- 保留人工核对 harness、effort、版本和模型别名。
- 自动生成 coverage 报告和差异。

**完成标准**：更新 Benchmark 不依赖临时命令或手工抄录。

### R-08 显式别名清单

**目标**：

- 将 Copilot 模型与能力/Benchmark 模型映射集中为带来源和核对日期的清单。
- 拒绝重复、冲突和指向已删除模型的别名。

**完成标准**：新增模型时能单独审阅匹配变化。

### R-09 LMArena 分页完整性

**问题**：刷新脚本目前每类配置只取前 100 行，排名更后的有效模型会缺少代理。

**目标**：

- 分页拉取直到满足完整覆盖或明确的停止条件。
- 记录抓取到的总行数和覆盖原因。

**完成标准**：不再因为固定的 100 行限制而静默遗漏模型。

## Candidate：尚未承诺

- 用户可调 input/output token 比例。
- 可切换的 Profile 权重预设。
- 数据源健康面板。
- Benchmark 结果差异历史和回归趋势。
- 导出当前筛选/Pin 结果。
- 可选的模型对比详情视图。

这些项目只有在产品需求、数据可行性和依赖预算明确后才会进入 Next。

## Non-goals

- 后端、数据库或账户系统。
- 直接读取 GitHub Copilot 实际账单。
- 旧版年度套餐倍率。
- 实时运行 benchmark。
- HTML 解析库、图表库、雷达图或 axios。
- 通过模糊名称匹配补齐能力数据。
- 把 Agent benchmark 结果宣称为纯模型绝对能力。

## 风险依赖

- Terminal-Bench、SWE-bench 和 LongCLI 都是 Agent + Model + Harness 结果。
- 当前多数模型依赖 LMArena 代理。
- 浏览器 CORS 决定了 LMArena 运行时实时刷新不可行。
- 直接依赖上限会影响类型检查和测试工具选择。
- 新模型、退役状态和 benchmark 分数可能随时变化。
